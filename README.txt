# Hotel Kilegal — site

## Antes de publicar
1. Substitua os blocos "FOTO..." pelas fotos reais do hotel.
2. Em `index.html`, troque `SEU ENDEREÇO AQUI` pelo endereço correto.
3. Troque `https://wa.me/55SEUNUMERO` pelo WhatsApp do hotel.
   - Exemplo: https://wa.me/5511999999999
4. Troque `https://instagram.com/` pelo Instagram oficial do hotel.
5. Troque os links do Google Maps pelo link exato da localização do Hotel Kilegal.

## Publicar no GitHub Pages
Crie um repositório público chamado `hotel-kilegal`, envie `index.html`, `estilo.css`, `script.js` e a pasta `imagens`, depois vá em Settings > Pages e selecione a branch `main` como fonte de publicação.
